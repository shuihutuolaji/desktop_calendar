## v1.6.0（2026-10-06，versionCode 4）— 同步桌面版 v1.6.0 第一梯队功能

### 1. 更强重复规则

- 新任务类型「**工作日任务**」：按节假日数据跳过周末与法定节假日（调休补班的周六
  照常算工作日），一次性生成未来约 10 周各期并自动续期；锚点落在假期自动顺延。
  类型标签循环切换：日→周→月→工作日；添加栏与编辑弹窗均可选。
- 周任务支持「**每 N 周**」（每周/每2周/每3周/每4周/每6周），间隔随系列持久化，
  补期按同一间隔推进。

### 2. 提前提醒

- 设置里可选：不提前 / 5分钟 / 10分钟 / 30分钟 / 1小时 / 1天。
- 到期前提前量先弹一次「⏰ 即将开始」本地通知（无「全部完成」按钮，不推企业微信），
  闹钟排程会把提前窗口起点纳入计算；到点照常弹提醒并可推企业微信。

### 3. 倒数日 / 纪念日

- 「日期计算」页新增第④节：添加每年纪念日 / 单次倒数日，可勾**按农历**——
  农历条目以后每年自动换算成公历（闰月日期不支持换算）。
- 月历格子角标：🎂 纪念日、⏳ 倒数日到点；当天有纪念日/倒数日到点时
  每天弹一次「🎉 今日纪念」通知。

### 4. 每日自动备份

- 启动/回前台时快照数据库到应用私有目录 `files/backup/`（先 WAL checkpoint 保证一致），
  24 小时内不重复，保留最近 10 份自动轮转；设置里可关闭。

### 5. ICS 日历订阅

- 设置里可填 .ics 订阅网址，「立即同步」把未来 6 个月内的事件按日期建为任务
  （📅 前缀，按日期+标题去重）；每天静默自动同步一次，失败不打扰。

### 兼容性

- 数据库自动升级：`tasks` 加 `interval` 列（默认 1=每周）、新增 `events` 表；旧数据不丢。
- 桌面版导出的 JSON/CSV 不含间隔信息，导入后按每周处理。

## v1.5.2（2026-10-04，versionCode 3）— 同步桌面版 v1.5.1 / v1.5.2 的修复

### 1. 旧的周/月任务自动升级为周期系列（修「只体现一次」）

- v1.1 只让**新添加**的任务按系列生成各期，旧任务没有系列号、仍是「顺延一行」。
- 现在启动 / 回前台时自动把没有系列号的旧周/月任务收编成系列
  （`adoptLegacySeries()`），`expandSeries()` 照常为它们补齐未来各期；
  只补系列号，不动任务内容与日期，幂等。
- 防逾期洪水：补期不回补早于本周（周任务）/ 本月（月任务）的历史期次。

### 2. 修 Bug：周期任务删除后会「复活」

- 删掉系列的最后一期（或「清理已完成」删掉已完成的那期）后，下次补期会把它
  当作缺期重新生成——删掉的待办回来了，已完成的记录变成新待办。
- 新增墓碑表 `series_skips`：删除本条 / 批量删除 / 清理已完成时先记墓碑再删行，
  补期时跳过；删除整个系列连墓碑一起清掉；清空导入时清空全部墓碑。

### 3. 导入备份：各期重新归队

- 导出文件不携带系列号，此前导入时每一期各自新建系列，补期后一份备份会被
  放大成成片重复任务。现在按（标题 + 类型 + 提醒时间）把各期归并回同一条系列
  （`Transfer.groupSeriesRows()`）。

### 4. 英文界面不显示农历 / 节气（数据源头硬开关）

- `Lunar.displayText()` 英文界面直接返回空串；月历节气槽在英文下同样不再显示。
  与桌面版 v1.5.1 同一口径，任何调用路径都不会再把农历数字带进英文界面。

### 5. 类型标签切成周/月后立即补期

- 点击任务把类型循环切换成周/月后，立刻生成未来各期（原来要等下次启动）。

## v1.1（2026-09-29，versionCode 2）— 同步桌面版 v1.5.0 的两项修改

### 1. 周任务 / 月任务按周、按月自动生成（原来只是"顺延一行"）

- 原来：`rollPending()` 把未完成的周任务**往后搬**——永远只有一条，
  上周没做的周报被搬到本周，日历上看不到"下周三还有周报"。与桌面版旧行为一致，同一个毛病。
- 现在（与桌面版同一套规则）：
  - `tasks` 表加 `series_id` 列（`onCreate` 建表带该列，旧库 `onOpen` 自动 ALTER，
    从桌面版拷来的老 `calendar.db` 也能直接用）。
  - 新增周/月任务时 `insertSeries()` **一次性生成未来各期**：周任务约 10 期（70 天窗口）、
    月任务约 13 期（400 天窗口）；每期独立一行、共享 `series_id`，各自可勾选完成、各自到点提醒，
    提醒时间各期相同。
  - `expandSeries()` 在**启动 / 回到前台**（`ReminderScheduler.onAppForeground`）时
    按窗口继续补期——滚动窗口，不会无限增长。
  - 月任务月末截断（1/31 → 2/28 → 3/31）。
  - 带 `series_id` 的任务**不再参与 `rollPending()` 顺延**（与桌面版一致）：
    没做完的那期保持"逾期"，历史可追溯，不会和本周那一期撞车。
  - 添加后 Toast 提示「已生成 N 期（到 YYYY-MM-DD）」。

### 2. 编辑任务：保存按钮 + 周期系列同步

- 编辑弹窗原来的确认按钮写「确定」，现改为 **「保存」**（与桌面版一致）。
- 周期系列（>1 期）新增：
  - 「☑ 应用到整个系列（后续各期同步）」（默认勾选）：
    - 只改标题 / 提醒 / 重要 / 置顶 → 同步到本条及之后各期（日期不变）；
    - 改日期或类型 → 以新日期为新锚点，撤掉其余**未完成**期次后重排（已完成的当历史保留）；
    - 改回「日任务」→ 撤掉其余未完成期次，本条脱离系列。
  - 「删整系列」按钮：**点两次确认**（按钮变成红色的"确认删除整个系列？"），避免误删一片。

### 3. 修订日志

- 新增本文件，作为该原生工程的修订历史（桌面版对应 `../CHANGELOG.md`）。
