# 桌面日历清单 · Windows 版详细指南

> 本文件是 Windows 桌面版的功能详解（原根目录 README）。项目总览请看根目录 `README.md`；
> 安卓版请看 `android-native/README.md`。

个人任务跟进小工具：月历视图 + 当日任务面板 + 全部清单，数据本地存储，无任何联网依赖。

## 功能

- **日历页**：月历格子直接显示每天的任务数量角标和前 3 条任务标题；
  点击任意日期，右侧面板即显示当天任务，可勾选完成、删除、快速添加。
- **任务类型与自动顺延**：添加任务时选「日任务 / 周任务 / 月任务」（周任务下拉选星期、
  月任务下拉选当月几号，默认跟随所选日期），未完成的自动顺延：
  - 日任务：当天没做完，次日（打开程序时）自动顺延，直到做完为止；
  - 周任务：所在周结束（进入下一周）还没做完，自动顺延到本周的同一天；
  - 月任务：所在月结束还没做完，自动顺延到本月同一天（31 号这类日期顺延到
    短月时按月末截断，如 1 月 31 日 -> 2 月 28 日）。
  - 已完成的任务永远留在原日期，不参与顺延。顺延在每次启动和跨天时自动执行。
- **任务提醒（日提醒/周提醒/月提醒）**：添加任务默认不提醒；勾选「提醒」后用下拉
  选择时:分（分钟按 5 分钟步进，勾选时自动预填下一个 5 分钟整点）。
  到「任务日期 + 提醒时间」时从屏幕右下角弹出置顶提醒窗（带提示音），
  可一键「全部完成」或「知道了」；错过时间后打开程序也会补弹。
  - 日任务每天到点都提醒、周任务每周、月任务每月——因为任务顺延后日期更新，
    提醒自然按周期重复，直到任务被完成为止。
  - 每条任务行会显示 `⏰HH:MM` 角标；**右键任务**可下拉选择修改或清除提醒；
    程序每 30 秒检查一次，漏开的提醒会在下次启动时补上（同一周期只弹一次）。
- 任务前的彩色小标签显示类型：「日」蓝 /「周」绿 /「月」黄，**点击标签可循环切换类型**。
- **全部清单页**：所有任务按日期排序，含类型/提醒列，状态分「逾期（红）/ 今天（蓝）/ 未来 / 已完成（灰）」，
  支持双击切换完成状态、批量删除、一键清理已完成。
- **导入 / 导出**（清单页右上角）：
  - 导出：JSON 备份（含日期、类型、提醒、完成状态的完整数据）或 CSV 表格（utf-8 带 BOM，
    Excel 双击直接打开）。
  - 导入：自动识别 JSON / CSV（导出的文件可直接导回；CSV 可在 Excel 里编辑后再导入）。
    导入时可选「清空现有后导入」（备份恢复）或「合并导入」（自动跳过重复）。
    无效行（坏日期、空标题、非法提醒时间）自动跳过或清洗。
- **法定节假日与调休**（默认开启）：月历上法定节假日整段标红（淡红底 + 节日名，
  如「中秋」）。数据来自 chinesecalendar 库（`pip install chinesecalendar`，
  每年国务院公布后更新）。
- **周数 / 农历 / 24 节气 / 休息日**（默认全开）：
  - 周数：月历最左列显示 ISO 周号；
  - 农历：每天显示农历日（初一显示月名，如「八月」），数据来自 cnlunar 库
    （`pip install cnlunar`）；
  - 24 节气：节气当天显示节气名（绿字，如「白露」「秋分」），优先于农历显示；
  - 休息日：休息日显示红色「休」角标、调休补班日显示蓝色「班」角标。
  - 以上四项都可在 ⚙ 设置里单独开关。
- **每周开始于周一或周日**：⚙ 设置里切换，日历排列与周数即时重排。
- **重要与置顶**：右键任务可「⭐ 标为重要」（未完成时红色显示，月历格子里同样标红）、
  「📌 置顶」（排在当天任务最前，月历与清单里显示 📌 前缀）。导入导出均包含这两个标记。
- **颜色自定义**（⚙ 设置）：
  - 日历字体颜色：预设黑/红/蓝/棕/紫 + 「自定义…」调色板，作用于月历日期数字；
  - 主题色：蓝/绿/紫/橙/红/青，影响任务角标数字、选中格底色、⏰ 提醒标签等；
  - **背景颜色**：默认/浅蓝/浅绿/浅粉/米黄/深灰 + 自定义调色板，全窗口生效
    （月历格子保持白色卡片，内容更突出）；
  - **背景图片**：选择本机图片（png/jpg 等）铺满窗口底层，内容浮于其上，
    随窗口大小自动缩放裁剪；图片会拷贝到 data 目录，原文件移动不影响显示；
    可一键清除。颜色改动即时生效并保存。
- **企业微信推送**（⚙ 设置里配置）：支持两种通道，可同时启用，推送时全部发送。
  - **群机器人 Webhook**（发到某个群）：群聊 → 群设置 → 群机器人 → 添加 → 复制地址，
    填入后点「测试」验证；
  - **自建应用**（发到个人企业微信，无需建群）：管理后台 → 应用管理 → 自建应用，
    取 CorpID（我的企业 → 企业信息）、AgentID 与 Secret（应用详情页）。填入后点「测试应用」。
    **注意：应用推送要求在该应用详情页配置「企业可信IP」，加上本机的出口 IP**，
    否则报 errcode=60020 IP 不在白名单；
  - 「推送今日待办」会先弹出**任务勾选框**（默认勾选未完成的），只推送你选中的任务；
  - access_token 本地缓存（有效期约 2 小时，自动刷新）；推送在后台线程执行不卡界面；
    凭据只保存在本机 settings.json，请勿外传该文件。
  - 常见错误：Webhook 测试报「93000 地址无效」= 复制的地址不完整或被改动过，
    请到群设置 → 群机器人 → 查看机器人重新复制完整地址；
    应用推送报「60020」= 把本机出口 IP 加入该应用的「企业可信IP」。
- **系统托盘**（v1.7.0 引入，v1.8.1/v1.8.2 增强）：
  - **启动即常驻**：程序一启动托盘图标就出现（v1.8.2），悬浮提示「今日待办 N 条」
    随任务实时更新；最小化或恢复窗口后图标都不消失；
  - 最小化时窗口缩进托盘而不是留在任务栏；
  - **左键**托盘图标恢复窗口；**双击 exe**（程序已在跑时）也会把窗口拉回前台——
    哪怕窗口正缩在托盘里（v1.8.2）；
  - **右键快捷菜单**：新增任务…（v1.8.1，不开主窗口直接录入）、显示主窗口、
    推送今日待办（未完成，直达企业微信）、清理已完成任务、打开设置、退出。
- **窗口标题**实时显示今日待办数量，最小化到任务栏也能瞄一眼。
- 今天高亮、选中日高亮；周一为一周起始。
- **⚙ 设置**（日历页右上角）：窗口透明度（50%–100% 滑杆即时生效）、窗口置顶
  （固定在桌面最前不被遮挡）、开机自动启动（写当前用户注册表 Run 项，无需管理员）、
  **日历字体 / 任务字体独立设置**（各自选字体族和字号，改动即时预览）。
  日历字体管月历格子的日期数字与任务预览行；任务字体管右侧任务面板和「全部清单」页。
- **位置记忆**：窗口拖到哪、多大，下次启动就恢复成什么样（含透明度、置顶与字体设置），
  可以把它当桌面便签一样常驻在屏幕任意角落。

## 启动

**双击 `DesktopCalendar.exe`**（独立单文件程序，约 12MB，无需安装 Python，节假日/农历数据已内置）。

源码方式仍可用（改代码调试时）：

```bash
python calendar_app.py        # 调试运行（带控制台报错）
run.bat                       # 用 Python 启动
```

**数据共用**：exe 和源码方式读写同一份 `data\calendar.db` 与 `settings.json`
（都在程序文件夹里，跟着 exe 走），互相切换不丢数据。

**拷到其他电脑**：整个文件夹复制过去，双击 exe 即可——exe 已内置全部依赖，
不需要装 Python 和任何库；只需在新电脑上重新勾一次「开机自启」，
企业微信应用推送如报 IP 白名单错误，到管理后台把新电脑的出口 IP 加进「企业可信IP」。

**开机自启**：⚙ 设置勾选「开机自动启动」即可（注册表指向当前程序，
用 exe 运行时指向 exe）。也可以手动把 exe 快捷方式放进 `shell:startup`。

**重新打包 exe**（改完代码后，本项目用 spec 方式，会把 CHANGELOG.md 一起打进去）：

```bash
set TEMP=C:\Users\W\AppData\Local\Temp
set TMP=C:\Users\W\AppData\Local\Temp
python -m PyInstaller DesktopCalendar.spec --noconfirm --distpath "." --workpath "C:\Users\W\AppData\Local\Temp\dc_build"
# 产物直接覆盖本文件夹的 DesktopCalendar.exe
```

> 注意：必须用**带 tkinter** 的 Python 打包（本机的 Python 3.13 未装 tkinter，
> 用 `C:\Users\W\AppData\Local\Programs\Python\Python312\python.exe`）。
> 打包前先关掉正在运行的日历，否则旧 exe 被占用、无法覆盖。
> 可选依赖 `chinese_calendar`（法定节假日）、`cnlunar`（农历/节气）、
> `Pillow`（背景图片）若已安装会被一起打进去，缺失也不影响启动。

## 修订日志

- 文件：`CHANGELOG.md`（**最新一条写在最上面**），程序内「设置 → 📜 修订日志」读取的就是它。
- 改代码的三步：① 改 `calendar_app.py` 里的 `APP_VERSION`；② 在 `CHANGELOG.md` 顶部补一条
  （写清现象 / 根因 / 改法）；③ 重新打包 exe（spec 的 `datas` 已包含该文件）。
- 当前版本：**v1.8.5**。
- 近期版本速览：
  - **v1.8.5**（改进）：三处日期输入（两日期相差、倒数日/纪念日添加、任务
    编辑改期）从手敲 YYYY-MM-DD 改为「年/月/日」上下选择框，天数随年月联动
    （闰年自动 29），也可继续手输。
  - **v1.8.4**（修复）：显示器热插拔/改分辨率后日历消失或卡在屏外边角，
    托盘「显示主窗口」救不回、只能重启或拔插屏幕。现恢复时会连带把窗口
    钳制回可见桌面，并监听系统显示器变化消息（WM_DISPLAYCHANGE）当场自动归位。
  - **v1.8.3**（修复）：修改国家/语言后日历浮在最上层、点「固定」也压不回去——
    切语言会整体重建界面，销毁了正持有焦点的输入框，导致「打字保护」闩锁
    （防压底层时抢走键盘焦点的机制）永久卡死，所有贴底校验被跳过。现重建前
    会先结束打字会话，且贴底校验前实时核对闩锁真实性（失效就地自愈，
    500ms 内恢复贴底）。
  - **v1.8.2**（修复+改进）：修「最小化到托盘后双击就退出」——根因是托盘消息
    回调在 Tcl 主循环里触发 GIL 重入把进程打死，托盘消息泵已移到独立线程，
    回调经队列回主线程；托盘图标改为**启动即常驻**（悬浮提示随任务实时更新）；
    缩在托盘时双击 exe 会把窗口拉回前台。
  - **v1.8.1**（新功能）：托盘右键新增**「新增任务…」**——不开主窗口直接录入
    （标题 + 今天/明天/后天 + 可选提醒时间 + 重要，回车添加）；同日同名自动拦截；
    周期任务仍走主窗口。
  - **v1.8.0**（新功能）：窗口长宽可调——固定（嵌桌面）模式拖窗口四边即可缩放
    （隐形把手，松手自动钳回屏幕），移动模式直接拖系统边框；设置里也能直接输入
    宽 × 高。框架文字（星期表头+日期）与内容文字（任务文字）可分别设置字号与
    颜色（设置里新增「内容文字颜色」，原「日历字体颜色」改名为「框架文字颜色」），
    全部即时生效，默认值即原样式。
  - **v1.7.3**（修复）：多屏状态下窗口半截在桌面外、尤其顶部整条被截在桌面上方
    （v1.7.1 只救「完全出屏」，漏了这种）。现在启动时会把窗口整体收进与它相交
    面积最大的那块屏幕内；保存设置前也会先钳制，坏坐标不再落盘。压住任务栏的
    有意摆放不受影响（钳制以屏幕物理边缘为界，不含任务栏避让）。
  - **v1.7.2**（修复）：同一个周任务在同一天出现数条——三个写入缺口造成
    （旧任务收编时逐行各编一条系列、同名任务重复添加无确认、编辑改日期无冲突检查）。
    现在有四道防线：数据库唯一索引兜底、收编按内容归并成一条系列、同名同期添加时
    弹窗确认、编辑撞期直接拦截；老库里已有的重复会在升级启动时自动清理（保留最早一条）。
  - **v1.7.1**（修复）：双击 exe 后看不到窗口——原因是从前副屏保存的窗口坐标在副屏
    断开后把窗口还原到了屏幕外（进程其实一直在跑）。现在启动时会自动把屏幕外的窗口
    拉回主屏；并新增**单实例保护**，重复双击只会把已有窗口带到前台，不再堆出多个进程。
  - **v1.7.0**（新功能）：最小化缩到系统托盘（不再留在任务栏），托盘悬浮提示今日待办数；
    托盘左键恢复窗口，右键快捷菜单：显示主窗口 / 推送今日待办（未完成）/
    清理已完成任务 / 设置 / 退出。

## 常见问题

- **双击 run.bat 一闪而过没弹窗**：先在 cmd 里跑 `python calendar_app.py` 看报错；
  多数是 pythonw 不在 PATH，改用完整路径或重装 Python 时勾选 Add to PATH。
- **exe 双击后像没启动（什么都看不到）**：多半是窗口被还原到了已断开的副屏坐标上
  （拔掉扩展屏/换显示器后）。v1.7.1 起程序启动时会自动把屏幕外的窗口拉回主屏；
  老版本可手动删除 `settings.json` 里的 `geometry` 一行后重启。另外从 v1.7.1 起有
  单实例保护：重复双击只会把已有窗口带到前台，不会再堆出多个进程。
- **同一个周任务在同一天出现好几条**：v1.7.2 起已修复。多半是当年重复添加过同名任务
  （各成一条系列，之后每个同星期几都会各出一条）。现在程序会在同名同期添加时弹窗确认、
  编辑撞期时拦截，且数据库有唯一约束兜底；升级后首次启动会自动清掉历史重复
  （同一系列同一天只保留最早一条）。手动清某一周的某一期用任务旁的 ✕；
  整条系列不要了用「删除整个系列」。
- **最小化到托盘后无法恢复，双击 exe 就退出**（v1.8.2 已修复）：旧版托盘消息回调在
  Tcl 主循环里触发 GIL 重入导致进程直接崩溃退出。现托盘消息泵已移到独立线程，
  回调经队列回主线程；且启动后托盘图标常驻，缩在托盘时双击 exe 会把窗口拉回前台。
  如果你用的还是旧版本，请更新到 v1.8.2 或以上。
- **修改国家和语言后日历浮在最上层、点「固定」也压不回去**（v1.8.3 已修复）：
  切语言会重建界面并销毁持有焦点的输入框，「打字保护」闩锁卡死导致贴底校验
  全部跳过。现重建前自动结束打字会话、校验前实时核对闩锁（失效自动恢复）。
  旧版本遇到此问题可先点一下窗口其他位置再切语言规避，或升级到 v1.8.3+。
- **热插拔外接屏后日历消失 / 卡在屏外边角、无法移动**（v1.8.4 已修复）：窗口
  停在了已消失显示器的幽灵坐标上，旧版托盘「显示主窗口」只恢复状态不看坐标。
  现恢复时自动钳制回可见桌面，且系统显示器变化消息一到就当场自动归位；
  万一还有角落情况，退出重启也能兜底。
- **想要周末标红、任务备注、提醒弹窗**：后续版本可加，提需求即可。
