# 桌面日历清单 · 安卓版 修订日志

> 与桌面版（`../calendar_app.py`）保持同一套业务规则。改代码：① 在 `CHANGELOG.md`
> **顶部**补一条说明，② 同步到桌面版（两边逻辑要一致），③ 需要时重新打 APK。
> 程序里「⚙ 设置 → 修订日志」读的就是本文件（要求放在 `main.py` 同目录）。

---

## v1.5.0（2026-09-29）— 同步桌面版三项修改

### 1. 周期任务（周/月）按周、按月自动生成

- 之前：添加任务**根本没有类型选择**，全部按「日任务」存一行，周任务/月任务形同虚设。
- 现在：
  - 添加栏加了 **日任务 / 周任务 / 月任务** 三个类型块；选周任务再选星期（周一~周日），
    选月任务再填几号；另有「提醒 HH:MM」（可空）。
  - `tasks` 表加 `series_id` 列（旧库自动 ALTER 升级，已有任务不受影响）。
  - 新增周/月任务时**一次性生成未来各期**（周约 10 期 / 月约 13 期，窗口常量
    `SERIES_HORIZON_DAYS`），每期独立一行、共享 `series_id`，各自可勾选完成、提醒时间相同。
  - 新增函数 `new_series_id / series_next / series_horizon_end / series_dates /
    expand_series`，以及 `Store.expand()`；**启动与跨天**时自动续期（滚动窗口，不无限增长）。
  - 任务行上会显示 `[周]` `[月]` 标签，一眼看出是自动生成的周期任务。
  - 添加后 Toast 提示「已生成 N 期（到 YYYY-MM-DD）」。

### 2. 修改任务：新增编辑弹窗 + 保存按钮

- 之前：**完全没有编辑功能**（只能删了重加）。
- 现在：任务行新增 ✏️ 按钮，打开「编辑任务」弹窗 —— 标题 / 日期 / 类型 / 提醒一次改齐，
  底部 **「保存」+「取消」**（保存后 Toast 提示「已保存」）。
- 周期系列多一项「☑ 应用到整个系列（共 N 期）」：
  - 只改标题/提醒 → 同步到本条及之后各期；
  - 改日期或类型 → 以新日期为新锚点，撤掉其余**未完成**期次后重排（已完成的当历史保留）；
  - 改回「日任务」→ 撤掉其余未完成期次，本条脱离系列。
- 系列任务另有「删整系列」按钮（二次确认，避免误删一片）。

### 3. 修订日志

- 新增本文件，设置弹窗里加「修订日志」按钮，点开可滚动查看全部历史改动。

### 兼容性

- 旧库自动补 `series_id` 列；没有该列值的老任务仍是普通任务，行为不变。
- 安卓版没有常驻提醒轮询（手机端靠系统通知另做），周期各期的 `remind_time` 已随系列写入，
  将来接通知可直接用。
